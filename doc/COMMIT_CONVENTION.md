# Commit Convention

## 형식

```
<type> <subject>

<body>

<footer>
```

## Type

| 타입 | 설명 |
|------|------|
| `feat` | 새 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | 문서 변경 |
| `style` | 코드 포맷, 세미콜론 등 (로직 변경 없음) |
| `refactor` | 리팩토링 (기능/버그 변경 없음) |
| `test` | 테스트 추가/수정 |
| `chore` | 빌드, 설정, 패키지 등 기타 변경 |

## 규칙

- `type`: `< >` 꺾쇠괄호로 감싸서 표기 (예: `<fix>`, `<feat>`)
- `subject`: 한글 사용, 50자 이내, 명령형, 마침표 없음
- `body`: 한글 사용, 72자 줄바꿈, 변경 이유와 내용 설명
- `footer`: 관련 이슈 참조 (`Closes #123`, `Refs #456`)

## 예시

```
<feat> 소셜 로그인 기능 추가

카카오, 구글 OAuth2 로그인 지원.
기존 이메일 로그인과 병행 사용 가능.

Closes #42
```

```
<fix> 긴급Fix 토큰 만료 시 무한 재시도 버그 수정

만료된 토큰으로 재시도 루프 발생 문제.
401 응답 시 즉시 로그아웃 처리로 변경.

Refs #78
```
